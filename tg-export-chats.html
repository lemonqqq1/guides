Telegram — как сохранить (экспортировать) переписку и файлы

Резервная копия чатов, фото и файлов из Telegram: официальный экспорт на компьютере по шагам.

Главное

В Telegram есть официальный экспорт, но он работает в Telegram Desktop (программа для Windows/macOS/Linux с telegram.org). В мобильном приложении полного экспорта нет.

Экспорт всех данных

  1. Скачайте Telegram Desktop на telegram.org и войдите в аккаунт.
  2. Меню (три полоски) → Настройки → Дополнительно → Экспорт данных Telegram.
  3. Отметьте, что сохранять: личные чаты, группы, каналы, фото, видео, файлы, голосовые, стикеры, список контактов.
  4. Выберите формат: HTML (удобно читать) или JSON (для программ).
  5. Выберите папку и нажмите «Экспортировать».

Экспорт одного чата

  1. Откройте нужный чат.
  2. Меню чата (три точки сверху) → «Экспорт истории чата».
  3. Настройте типы медиа и период, укажите папку, нажмите «Экспортировать».

Если Telegram просит подтвердить

Для безопасности Telegram может запросить подтверждение на другом вашем устройстве. Откройте Telegram на телефоне и разрешите экспорт. Если подтверждения нет, подождите и повторите.

Советы

  • Большие чаты с видео весят гигабайты: сначала снимите галочки с видео и файлов, потом при необходимости повторите.
  • Если экспорт остановился, нажмите «Продолжить» либо разбейте на несколько чатов.
  • Архив содержит личную переписку: храните его надёжно и не отправляйте незнакомым.
  • Сохранить отдельные сообщения быстро можно через «Избранное»: перешлите их себе.
