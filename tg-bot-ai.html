Telegram-бот без программиста: сделать своего с помощью ИИ

Сколько стоит бот, что можно сделать самому за вечер и когда проще заказать.

Что нужно

  • Аккаунт Telegram и компьютер с Python (python.org, галочка «Add to PATH» при установке).
  • Любой ИИ-помощник для кода: ChatGPT, Claude, Gemini.
  • Час-два времени для простого бота: ответы на кнопки, анкета, приём заявок, выдача файла, напоминания.

Шаг 1. Создать бота

  1. Открой @BotFather и отправь /newbot.
  2. Задай имя и username (должен заканчиваться на bot).
  3. Скопируй токен. Это ключ к боту: никому не отправляй и не публикуй.

Шаг 2. Написать код через ИИ

Скопируй в ИИ такой запрос, подставив свою задачу:

«Напиши Telegram-бота на Python с библиотекой aiogram 3. Задача: [опиши, что должен делать бот, какие кнопки, какие ответы]. Токен читай из переменной окружения BOT_TOKEN. Дай полный код одним файлом и инструкцию запуска для Windows по шагам.»

  • Чем конкретнее описание, тем лучше результат. Укажи тексты кнопок и что происходит после каждой.
  • Если вышла ошибка, скопируй весь её текст обратно в ИИ и попроси исправить.

Шаг 3. Запустить

  1. Создай папку, положи туда bot.py.
  2. В командной строке: pip install aiogram
  3. Задай токен: set BOT_TOKEN=твой_токен, затем python bot.py.
  4. Открой бота в Telegram и нажми Start.

Где держать, чтобы работал всегда

  • Свой ПК: бесплатно, но бот спит, когда компьютер выключен.
  • VPS: обычно от нескольких сотен рублей в месяц. Подходит для бота, который отвечает круглосуточно.
  • Бесплатные хостинги для небольших ботов бывают, но условия и лимиты меняются: смотри актуальные на их страницах.

Сколько стоит заказ

  • Простой бот (меню, ответы, заявки): ориентир 150–500 ₽ за разработку.
  • Бот с базой данных, оплатой, админ-панелью: дороже, цена зависит от объёма задач.
  • Хостинг оплачивается отдельно.
