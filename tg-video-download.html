Telegram — скачать видео по ссылке: бот, сайт, свой бот

Четыре способа получить видео из YouTube, TikTok, Instagram: от готовых ботов до собственного бота за вечер.

Способ 1. Готовый бот в Telegram

  1. В поиске Telegram набери «скачать видео» или «video downloader» и открой бота с большим числом пользователей.
  2. Нажми Start, отправь ссылку на видео, получи файл.
  3. Боты периодически блокируют и переименовывают, поэтому держи 2–3 запасных. Не вводи в боте пароли и не соглашайся на «подписку за SMS».

Способ 2. Сайт-загрузчик

  • Бесплатные сайты-загрузчики (например, cobalt.tools): вставляешь ссылку, получаешь файл. Работают из браузера на ПК и телефоне.
  • Закрывай рекламу и всплывающие окна, ничего не устанавливай и не разрешай уведомления.

Способ 3. yt-dlp на компьютере

Самый стабильный вариант, если видео много или нужно лучшее качество.

  1. Скачай yt-dlp с официальной страницы github.com/yt-dlp/yt-dlp (раздел Releases). Для склейки видео и звука нужен ещё ffmpeg.
  2. В командной строке: yt-dlp "ссылка"
  3. Только звук: yt-dlp -x --audio-format mp3 "ссылка"
  4. Ограничить качество: yt-dlp -f "bv*[height<=720]+ba/b[height<=720]" "ссылка"

Способ 4. Свой бот: ссылка → видео (Python)

  1. В Telegram открой @BotFather, команда /newbot, придумай имя. Получишь токен: это пароль бота, никому его не показывай.
  2. Поставь Python и библиотеки: pip install pyTelegramBotAPI yt-dlp
  3. Сохрани код как bot.py, вставь токен и запусти python bot.py:
import os, telebot, yt_dlp
bot = telebot.TeleBot("ТВОЙ_ТОКЕН")

@bot.message_handler(func=lambda m: m.text and m.text.startswith("http"))
def dl(m):
    bot.reply_to(m, "Скачиваю...")
    opts = {"outtmpl": "v_%(id)s.%(ext)s", "noplaylist": True,
            "format": "best[ext=mp4][filesize<49M]/best[ext=mp4][height<=480]/best"}
    try:
        with yt_dlp.YoutubeDL(opts) as y:
            info = y.extract_info(m.text, download=True)
            path = y.prepare_filename(info)
        with open(path, "rb") as f:
            bot.send_video(m.chat.id, f)
        os.remove(path)
    except Exception as e:
        bot.reply_to(m, "Не получилось: " + str(e)[:200])

bot.infinity_polling()
  • Бот отвечает, пока запущен твой компьютер. Для работы круглосуточно нужен сервер (VPS) или ПК, который не выключается.
  • Обычный бот отправляет файлы до 50 МБ. Для длинных видео ставь качество пониже.

Важно

  • Скачивай только то, что можно: свои видео и контент с разрешением автора. Чужие ролики нельзя перезаливать как свои.
  • Если сервис изменил защиту и бот перестал работать, обнови yt-dlp: pip install -U yt-dlp.
